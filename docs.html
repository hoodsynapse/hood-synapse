Request envelope

Every call is an HTTP POST with the same JSON body. Only method and params change between calls.

No API key, no account, no headers beyond content type.

Everything returns hex. Heights, balances, gas and timestamps are hex strings. Decode with parseInt(h,16), or BigInt(h) when the value can exceed 2⁵³.
REQUESTcurl
curl -X POST https://rpc.mainnet.chain.robinhood.com \
  -H 'Content-Type: application/json' \
  -d '{"jsonrpc":"2.0","method":"eth_blockNumber",
       "params":[],"id":1}'
RESPONSEjson
{ "jsonrpc": "2.0", "id": 1, "result": "0xdec54d" }

Hood Synapse ships its own HTTP API on top of the chain. Same live data as the console, already cleaned up: decimal numbers instead of hex, ISO timestamps, and ArbOS system transactions identified and counted separately.

/api/block/latest

Blocks come back with the fields you actually reason about. userTxCount excludes ArbOS bookkeeping transactions, so your metrics are not inflated. Orbit fields (l1BlockNumber, sendCount, sendRoot) are included, already decoded.

Responses are edge-cached for a few seconds; historical blocks are cached long, since they never change.

No key, but be fair. The API sits on public infrastructure. For sustained heavy reads, run against the RPC directly or use a dedicated provider.

The Index

history · aggregates
Why an index exists

An RPC answers for the present. Ask it for last week and it has nothing to say. Hood Synapse runs its own indexer over Robinhood Chain and keeps the result, so the past stays queryable.

The chain produces roughly 10 blocks per second (~864k per day) and the public RPC rate-limits sustained bulk reads. Indexing every block is not workable at that rate, so the indexer samples every 100th block and rolls those samples into daily aggregates.

What that means for you. Daily statistics (transactions, gas, block cadence) are accurate and representative. Per-block history is a sample, not a complete archive — and /api/index-status tells you exactly what the index holds.
DAILY STATISTICScurl
curl https://hoodsynapse.xyz/api/daily?days=30
RESPONSEjson
{
  "days": [{
    "day": "2026-07-26",
    "blocks": 876,          // samples that day
    "txs": 12968,
    "userTxs": 9204,       // system txs excluded
    "avgBaseFeeGwei": 0.0509,
    "avgBlockTimeSeconds": 0.872
  }]
}
/api/history

Walk backwards through indexed blocks. Use limit to size the page and before to paginate — each response returns nextBefore for the next call.

PARAMETERS
limit1–200, default 25
beforeblock number to page back from
PAGINATEjavascript
let before = null, all = [];
for (let i = 0; i < 5; i++) {
  const url = 'https://hoodsynapse.xyz/api/history?limit=100'
            + (before ? '&before=' + before : '');
  const page = await fetch(url).then(r => r.json());
  all.push(...page.blocks);
  before = page.nextBefore;
  if (!before) break;
}

Tokens & RWAs

equities · funds · memecoins
GET /api/tokens

Robinhood Chain carries tokenized real-world assets next to native tokens. NVIDIA, Tesla, Apple, GameStop, SpaceX, the S&P 500 and iShares Silver all move here as ERC-20s, alongside stablecoins and memecoins.

The scanner reads Transfer logs continuously and ranks tokens by activity. Classification comes from Robinhood's own on-chain naming — tokenized assets carry a • Robinhood Token marker in the token name.

A second pass records the market: priceUsd, priceChange24h, liquidityUsd and volume24h, read from DEX pairs on this chain, plus holders from the chain explorer. The busiest tokens are refreshed every minute; the long tail is filled in over time. marketAt says when a row was last priced.

PRICE HISTORY
historycontract address — returns a daily series instead of the list
days1–365, default 90

Each day carries open, high, low, close, liquidityUsd, volume24h and samples — how many readings that day was built from.

PARAMETERS
kindrwa · equity · fund · private · stable · meme · infra
limit1–200, default 25
rwa is an umbrella: equities, funds and private companies in one call. Everything else is a direct category match.

Transfer counts are relative. They accumulate from when the scanner first saw a token, not from genesis. Use them to compare activity, not as a lifetime total.
DAILY HISTORYcurl
curl "https://hoodsynapse.xyz/api/tokens?history=0xd060…&days=30"
History has no backfill. A token's series starts the day Hood Synapse first priced it. The prices before that were never recorded anywhere readable, so they are absent rather than estimated.
Price is the on-chain DEX price. It comes from the deepest pair on Robinhood Chain, not from a reference exchange. A tokenized equity trading against a few thousand dollars of depth can sit well away from its off-chain price, so read liquidityUsd next to it. Tokens with no pair return null rather than a guess.

Polling for new blocks

The public endpoint is HTTP only — no WebSocket subscriptions. New blocks are discovered by polling.

Poll at block time. Blocks land every ~4s. Polling every second triples your request count and hands you the same block three times.
POLLERjavascript
let seen = 0;

setInterval(async () => {
  const b = await call('eth_getBlockByNumber', ['latest', false]);
  const h = parseInt(b.number, 16);
  if (h === seen) return;
  seen = h;
  console.log(h, b.transactions.length, 'tx');
}, 4000);

Accounts

balances · code
eth_getBalanceVERIFIED

Balance in wei at a given block.

PARAMS
address20-byte hex
block'latest' or hex height
Use BigInt. Wei values overflow JavaScript's safe integer range. Convert with BigInt(hex) and only cast to Number after dividing by 1e18.
CALLjavascript
const wei = await call('eth_getBalance', [addr, 'latest']);
const eth = Number(BigInt(wei)) / 1e18;
// 0.000237
eth_getCode

Returns deployed bytecode. An empty result (0x) means the address is a plain wallet, not a contract — the cheapest way to tell them apart.

RESPONSEjson
{ "result": "0x" }        // EOA, not a contract

Transactions

submitted vs executed
eth_getTransactionByHash VERIFIED
eth_getTransactionReceipt VERIFIED

A transaction has two halves and you need both: what was submitted (the transaction) and what happened (the receipt).

Mined is not successful. A reverted transaction still occupies a block and still burns gas. Check receipt.status === '0x1' before treating anything as done.
CAPTURED FROM MAINNETpython
h  = '0xb951c0274bd58288b01dbf3a94965a7efdfed4c2…'
tx = call('eth_getTransactionByHash', [h])
rc = call('eth_getTransactionReceipt', [h])

# from   0x6d9da725…  →  to  0x24d7cd0d…
# status 0x1  (success)
# gas    189,966
# logs   5
System transactions

Most blocks open with an internal ArbOS transaction: sender equals recipient, value is zero, gasUsed is 0x0.

It is chain bookkeeping, not user activity.

Filter it out. Counting raw transactions.length inflates every metric you publish by one per block.
SYSTEM TX SHAPEjson
{
  "from":    "0x…000a4b05",
  "to":      "0x…000a4b05",   // identical
  "value":   "0x0",
  "gasUsed": "0x0"
}

Orbit internals

not on ethereum
l1BlockNumber

The Ethereum L1 block this L2 block is anchored to. An L2 block is only as final as the L1 block behind it — read this when you need real finality, not just inclusion.

FIELDjson
"l1BlockNumber": "0x1863755"   // 25,573,205
sendRoot · sendCount

Messages travelling L2 → L1 (withdrawals, cross-chain calls) accumulate into a merkle tree. sendRoot is its current root; sendCount is the running total of queued messages.

Watch sendCount to detect outbound activity without parsing every transaction.

FIELDSjson
"sendRoot":  "0xf6c227e8bd780bce1fd394c5bcd9513f…",
"sendCount": "0x227"                // 551
The miner field is the sequencer

There is no mining and no validator here. The miner address is a readable marker — decode its tail as ASCII and it spells what it is.

DECODEjavascript
const m = '0xa4b000000000000000000073657175656e636572';
Buffer.from(m.slice(-18), 'hex').toString();
// → "sequencer"

handle these
eth_syncingUNAVAILABLE

Not exposed on the public endpoint. Clients that assume it exists will read undefined and carry on silently.

Check for error first. A JSON-RPC failure returns HTTP 200 with an error object — inspect it before touching result.

  "error": {

M

Limits

going to production
The public endpoint

Free, keyless, CORS-open — ideal for reading, prototyping and browser apps. It is rate limited and not intended for production.

Move to a dedicated provider once you need archive history, throughput, or an uptime guarantee: Alchemy, QuickNode, Blockdaemon, dRPC, Validation Cloud.

Never sign in the browser. Everything documented here is read-only. Private keys belong in a wallet the user controls or a backend you control — never in page code.
